# 待办清单（单文件静态网页）

一个零依赖、零构建、可直接双击打开的待办清单网页。所有任务保存在浏览器的 `localStorage` 中，刷新或关闭页面后依然保留。

支持 Enter 快速新增，Esc 清空输入

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `index.html` | 完整应用（HTML + CSS + JavaScript 全部内联），唯一的运行文件 |
| `README.md` | 本使用说明 |

## 快速开始

1. 直接双击 `index.html`，或在浏览器里选择「打开文件」，页面即可使用。
2. 也可用任意静态服务器托管（可选，仅为体验，非必需）：

   ```bash
   # 在本目录执行，任选其一
   python3 -m http.server 8000
   npx serve .
   ```

   然后访问终端里打印的地址即可。

> 本项目不需要安装依赖、不需要打包、不联网；所有图标为内联 SVG 与 Emoji，字体使用系统自带字体。

## 功能说明

- **新增任务**：在顶部输入框输入内容，按 `Enter` 或点击「添加」按钮；文本首尾空格会被自动去除，单条最长 200 字。
- **完成 / 取消完成**：点击任务左侧的圆形按钮，任务文字会加删除线并变灰，状态立刻写入本地存储。
- **删除任务**：点击任务右侧的垃圾桶按钮删除；删除后底部会出现提示条，点击「撤销」可在 5 秒内恢复该任务。
- **批量清除**：点击右下角「清除已完成」一次性删除所有已完成任务（没有已完成任务时按钮自动禁用）。
- **筛选**：顶部「全部 / 未完成 / 已完成」三个按钮切换列表视图，统计数字同步变化。
- **统计**：底部显示任务总数、未完成数、已完成数；顶部工具栏也显示未完成与已完成数量。
- **快捷键**：输入框内按 `Esc` 可清空已输入的内容。
- **空状态提示**：没有任务时显示对应的引导文案（区分「还没有任务」「所有任务都已完成」「还没有已完成的任务」）。

## 数据存储说明

- 存储位置：浏览器 `localStorage`，键名为 **`todo.todolist.v1`**。
- 数据格式（JSON 数组）：

  ```json
  [
    { "id": "m1c2ab-3f4d5e", "text": "写完周报", "done": false, "createdAt": 1731800000000 }
  ]
  ```

- 数据只保存在**当前浏览器 + 当前站点**下，不上传任何服务器；无痕/隐私模式下浏览器可能禁用存储，此时页面顶部会给出红色提示，任务仅在本次会话内有效。
- 清除数据：浏览器开发者工具 → Application → Local Storage → 删除 `todo.todolist.v1`；或点击页面里的「清除已完成」逐项清理。
- 同一浏览器打开多个标签页时，一个标签页的改动会通过 `storage` 事件同步到其它标签页。

## 浏览器兼容性

在当前版本的 Chrome、Edge、Firefox、Safari 上均可正常使用（需支持 `localStorage`、`Array.prototype.filter`、`dataset`）。界面会跟随系统的深色 / 浅色模式自动切换，并适配移动端窄屏。

## 常见问题

**Q：换了浏览器或电脑，任务不见了？**
`localStorage` 按浏览器与站点隔离，且不随文件拷贝同步。想在多设备间共享，需要自行接入后端存储，本项目不含任何网络请求。

**Q：用 `file://` 打开时数据能保存吗？**
绝大多数现代浏览器允许 `file://` 页面使用 `localStorage`（同一浏览器下的所有本地文件共享一份存储）。个别浏览器或隐私设置下会被禁用，此时页面顶部会出现提示，数据仅保留到关闭页面为止。若遇到限制，可改用上面的静态服务器方式打开。

**Q：如何重置为空白状态？**
清空该键的存储值即可，或直接删除 `localStorage` 中的 `todo.todolist.v1`。

## 二次开发提示

脚本全部写在 `index.html` 底部 `<script>` 中，结构清晰、均为普通函数，方便改动：

| 函数 | 职责 |
| --- | --- |
| `init()` | 绑定 DOM 事件、载入数据、首次渲染 |
| `loadTasks()` / `saveTasks()` | 读写 `localStorage`（含异常兜底） |
| `addTask()` / `toggleTask()` / `deleteTask()` | 增 / 改 / 删，并触发持久化与重绘 |
| `filterTasks()` | 按当前筛选条件过滤任务 |
| `render()` | 重建列表与统计信息 |
| `showToast()` / `undoDelete()` | 提示条与撤销删除 |
| `captureFocus()` / `restoreFocus()` | 列表重绘后把键盘焦点还回同一个任务按钮 |

若要支持任务编辑、截止日期、优先级等，可在 `addTask()` 写入的字段上扩展对象结构，并同步修改 `createTaskNode()` 的渲染逻辑即可；存储键名带版本号，改数据结构时建议同步升版本（如 `v2`），避免读到旧数据。
