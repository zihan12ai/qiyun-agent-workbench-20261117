工作台使用说明

① 新建工作，选择代码开发或材料分析。

② 描述任务，实时查看执行步骤。

③ 在右侧预览、查看源码或下载成果。

④ 在同一个工作中继续提要求；切换工作后，记录和文件仍会保存。

离线演示不调用模型，只执行待办网页和 CSV/文本报告的预置流程。发送“演示失败”可以查看异常恢复。

真实模式：在服务端 .env 设置 AGENT_MODE=codex、CODEX_API_KEY、CODEX_MODEL 和 OPENAI_BASE_URL，重启服务。要求 API 兼容 Responses 协议。

单文件最多 5 MB。演示分析支持 CSV、TXT、MD。刷新、离开网页不会停止正在执行的任务。
